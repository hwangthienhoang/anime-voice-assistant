# Model VRM

Đặt file nhân vật của bạn ở đây với tên `avatar.vrm` khi cần thử model.

Sân khấu Vue hiện tự tải `/models/avatar.vrm`. Model đang dùng có metadata tên **Paimon** và điều khoản không cho phép thương mại hoặc phân phối lại; file được `.gitignore` và không đưa vào commit. Nếu thay model, cần kiểm tra quyền sử dụng của file mới. Xem [migration guide](../../../docs/FRONTEND_MIGRATION.md).

Nguồn model:
- VRoid Studio (tự tạo, xuất VRM): https://vroid.com/en/studio
- VRoid Hub (chọn model cho phép sử dụng): https://hub.vroid.com
- Booth.pm (model mua/tải miễn phí): https://booth.pm

Lưu ý bản quyền: mỗi model có điều khoản riêng về việc dùng trong ứng dụng, phát trực tiếp hoặc thương mại.
File `.vrm` được đưa vào `.gitignore` nên sẽ không bị commit nhầm.
